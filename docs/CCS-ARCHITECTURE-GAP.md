# CCS Architecture Gap Analysis

## Executive Summary

**Current State**: CCS implementation produces worse artifacts than legacy path
**Root Cause**: Treating FWPT snapshots as coefficients instead of streaming subband signals
**Solution**: True streaming coefficient-domain oscillator with polyphase IDWPT

---

## The Maximal Solution

The architecture that gives everything we wanted:

> **A true streaming coefficient-domain oscillator (CCS Mode A) feeding a polyphase IDWPT, with CMMM operating on persistent subband time-series state, and *no* FWPT anywhere in the voice path.**

This simultaneously provides:

- Perfect oscillator behavior (pitch-exact, phase-continuous)
- Arbitrary waveforms via tables
- No block clicks, no combing, no phase artifacts
- Full operator algebra power (CMMM)
- Deterministic FPGA-friendly behavior
- IDWPT used as synthesis, not analysis
- Forward pass optional / external only
- Real mathematical continuity guarantee

## The Key Insight

**Wavelet coefficients are NOT spectral snapshots.**
They are **time-domain subband signals**.

The coefficient state should be:

```
c[ℓ][k] where:
  ℓ = 0..L-1  = wavelet leaf / subband
  k = 0..K-1  = time samples *within* the subband
```

These are **streaming**, persistent signals that evolve over time.

### What We Had (Wrong)

```
Block N:
  audio_ref = generate_sine(phase_N)
  coeffs = FWPT(audio_ref)  ← Snapshot!
  IDWPT(coeffs) → audio
```

Coefficients jump discontinuously each block because FWPT produces a snapshot
of "how much energy is in each band for THIS specific 64-sample window."

### What We Need (Correct)

```
Offline (once per waveform):
  - Take a perfect bandlimited waveform
  - Run analysis filterbank offline
  - Record subband signals as phase-indexed tables

  CoeffLUT[waveform][leaf ℓ][time k][phase p]

Runtime:
  phase += Δφ
  (p, α) = phase index + fractional
  c_base[ℓ][k] = lerp(
      CoeffLUT[w][ℓ][k][p],
      CoeffLUT[w][ℓ][k][p+1],
      α
  )
```

This is:
- Table-driven
- Phase-continuous
- Pitch-exact
- Block-independent

No FWPT. No snapshots. No clicks.

## Correct Pipeline Architecture

### 1. CCS (Coefficient-domain Carrier Synthesizer)

Generates **subband signal samples**, not audio.

### 2. CMMM Operators

Act on **persistent subband time-series**:

```
c_state[ℓ][k] ← CMMM(
    c_state[ℓ][k],
    c_base[ℓ][k],
    operators,
    tail safety
)
```

- Diffusion, shear, catastrophe are *real transformations*
- Tail ops guarantee boundedness and legality
- Mathematically stable and musically expressive

### 3. IDWPT (Synthesis Filterbank)

Pure synthesis, polyphase, streaming:

```
audio_block = IDWPT_streaming(c_state)
```

Properties:
- Polyphase filterbank
- Maintains internal state across blocks
- Consumes K subband samples per block
- Produces 64 audio samples
- **No windowing required**
- **No safety OLA required for correctness**

Continuity is guaranteed by construction.

### 4. FWPT (Optional, External Only)

Allowed only for:
- Offline table generation
- External audio analysis
- Experimental effects
- Debugging / visualization

**Never** required for sound generation.

## Why Problems Occurred

| Problem | Why It Happened | How Maximal Solution Fixes It |
|---------|-----------------|-------------------------------|
| Clicks at block boundaries | Snapshot coefficients | Streaming subband signals |
| 750 Hz combing | Phase-variant masking | Phase-invariant synthesis |
| DC offsets | Misused coefficients | Coeffs are time-domain |
| Wet/dry phase fights | Two audio paths | One synthesis path |
| Safety windows causing tone | Fighting discontinuity | No discontinuity exists |
| FWPT cost too high | Unnecessary analysis | Removed from voice path |
| Conflicting specs | Mixed abstractions | Single consistent meaning |

## Continuity Guarantee

Let each coefficient stream be generated by:

```
c_{ℓ,k}(t) = A_{ℓ,k} * sin(φ(t) + θ_{ℓ,k})
```

Where:
- φ(t) is continuous
- Operators are Lipschitz-bounded
- Tail clamps magnitude and slope
- IDWPT is linear and time-invariant

Therefore:
- c(t) is continuous
- x(t) = IDWPT(c(t)) is continuous
- No ε-jump exists at block boundaries

**You cannot get clicks unless you intentionally inject them.**
