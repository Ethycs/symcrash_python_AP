Mode A encoding proposal audit, 2026-10-30

Implementation baseline: root 497aaeb / documentation 88a15a7.
Reproduce: pixi run python tools/audit_mode_a_encoding.py
Requires the existing full, validated SYMLUT02 image; does not build it.

Governing requirements:
- WSE-STD-210 sections 1.3 and 3.1: int16 coefficients and matching Q32 generation.
- WSE-STD-RAM-SUBSYSTEMS section 2.2: shared 4 MiB maximum LUT/basis allocation.
- CCS-BRAM-128KB-32VOICE: older int8/half-phase storage proposal under audit.

Measurement scope:
640 source tables: five native waves at all 128 nominal MIDI notes, each
64 leaves x K4 x P64. No detuned-pitch table or reconstructed-audio sweep.
Difference calculations widen to int64 before arithmetic. Half-phase error
is abs(LUT[leaf,k,p] + LUT[leaf,k,p+32]) before any output saturation.
It is a coefficient discrepancy, not an audio-error measurement.

The proposed floor codec is separately checked over all 65,536 int16 values.
The scalar identity source - 256*floor(source/256) independently gives 0..255.
Zero mean and periodicity do not imply half-wave antisymmetry; even harmonic
content violates that condition. Integer source/transform arithmetic also
prevents exact negation in the otherwise approximately symmetric waves.

Storage figures for hypothetical compressed pitch tables count native payload
only: no directory, legacy tables, Mode B, caches, staging or other resources.
Half-phase figures deliberately grant the invalid all-wave symmetry assumption
to show that this saving would still leave the exhaustive image over budget.
The older recommended K4 four-wave component is 32,768 bytes, not 16 KiB.
WSE-STD-210 does not require a stored table for every integer-cent pitch;
these large totals describe the current exhaustive implementation choice.

No production arithmetic, datatypes, N/K/P, resource image, pitch behavior,
golden hash or test threshold changed. No codec has been adopted. The current
Mode A memory failure remains open, along with target-wide realtime costs.
The unused HalfPhaseLUT prototype in composite_osc.py is not the current VM
playback path; no quality qualification is claimed for that prototype.

Validation:
- Repeated scan matches every prior captured extremum and worst-case location.
- Independent scalar division identity agrees with the full-int16-domain bound.
- CLI help works; a missing image fails without generating an image.
- Relative Markdown links in the five changed documentation files resolve.
- Full synth regression was not repeated for this diagnostic/docs-only change.
  Last runtime baseline remains 5,579 passed / 14 skipped at root 497aaeb.
