DMA burst engine evidence - 2026-10-30

Scope: aligned READ/WRITE primitive from WSE-STD-BRAM-RAM section 5.
The documented descriptor remains 64 bits; length 1..255 units of 16 bytes.
Payloads are opaque. No audio type, transform dimension, precision, waveform
resource, golden hash or realtime threshold changes. Python suite not repeated.

This profile uses byte addresses, preserving the 16-bit BRAM field: lower 64 KiB
only, including coefficient 0x8000..0xffff. Full 128 KiB mapping needs an adapter.
Unaligned, inactive, zero-length, wrapped or overrun requests fail before memory
access; scatter/gather types report unsupported. Priority metadata is preserved;
the service-class to wire-priority mapping and queue remain unimplemented.

Every accepted RAM request receives one ordered response, including committed
writes. Read responses directly write staging; response errors suppress their
write. A two-entry write FIFO counts pending synchronous BRAM reads as reserved
capacity. Handshakes preserve stalled payloads. Completion waits for every
response and remains stable until consumed. Partial successful writes are not
rolled back. The buffer owner must publish only successful complete transfers.

Reset aborts local validity; the adapter must be reset/flushed too. There is
no generation tag permitting old responses after reset. Earlier committed
memory writes remain committed. No PHY/adapter/reset-domain proof is claimed.

Ideal service from descriptor acceptance: L+1 read, L+3 write, one beat/clock
after startup; completion/next-descriptor handshakes add 2 clocks. Every length
1..255 in both directions checks these counts. MAX_CYCLES=40000 follows the
0.4 ms reference DMA window. Completion exactly at the limit is allowed.
The live deadline_missed signal reports an unfinished late transfer; status
persists through completion. Counter saturation: 2^32-1. A per-transfer alarm
does not prove aggregate DMA admission or the 133333-cycle complete audio budget.

Final validation command:
pixi run python -m pytest tests/conformance/test_hdl_dma.py tests/conformance/test_hdl_dma_evidence.py -q

11 passed in 25.06s
1,394 descriptor cases; 2,486,336 requested payload bytes; maximum observed service 678 clocks.

Six simulator runs: complete length sweep at 40000 and boundary-window subsets
at 1/2/3/4/8. Thirteen reset probes per run. Full-BRAM comparisons, address upper
bounds/wrap, all payload bits, malformed requests, unsupported types, response
errors at first/middle/last, input/output stalls and stable completion. The
maximum 255 requests are also accepted before any response returns, checking
full outstanding-counter endpoints and late completion. RAM error tests are
included in requested byte counts; those failed beats are not claimed committed.
Five evidence guards reject modified/missing source or netlists and altered
configuration before tool lookup. Optional simulator skips are not acceptance.

The final RTL has not changed after successful simulation/synthesis/routing.
Test observability and the case with 255 outstanding requests were added afterward;
the complete six-run simulation suite was rerun against the same final RTL.

Final synthesis: pixi run synth-hdl-dma; Yosys check -assert passes.
293 LUT4, 131 FF, 118 CCU2C, 32 DPR16X4, 17 PFUMX, 5 L6MUX21. Zero DSP/BRAM.
32 logical payload bytes occupy 256 physical distributed-RAM bytes. No queue,
staging-buffer, external adapter or PHY allocation is included.

Final routing: pixi run route-hdl-dma. Three seeds return 0 and pass 100 MHz,
122.73..131.29 MHz. Experimental out-of-context excludes board I/O and global
clock routing. No LPDDR bandwidth, device or mapped-netlist equivalence claim.

Priority scheduling, two-block prefetch, buffer ownership, scatter/gather,
upper-bank mapping, aggregate working memory, DMA admission and full integration
remain open. Current coefficient-storage gate still fails independently.
