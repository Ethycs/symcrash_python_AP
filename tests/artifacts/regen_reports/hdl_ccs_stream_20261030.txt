Requirements: WSE-STD-070A leaf-major coefficient layout and CCS rendering;
WSE-STD-BRAM-RAM sections 3.1/5.3/8/11 double buffering, complete-before-DSP,
two-block prefetch and graceful cache-miss handling.

The new ccs_stream connects the unchanged owner and decoder to physical
payload RAM, a bounded two-word feeder and complete-block replay storage.
The simulation additionally executes the unchanged priority queue and burst
engine against an ordered RAM-adapter model. Carrier/operator generation,
full voice scheduling and the LPDDR3 PHY are not implemented by this module.

N=64, K=2/4/8, signed 16-bit coefficients, headroom, RNE, wide lifting and
node saturation remain unchanged. Frame layout is c[leaf*K+slot], with the
lower-addressed coefficient in the lower 16 bits of each 128-bit memory word.
Two payload banks need 512/1,024/2,048 logical bytes at 0x8000 in the existing
coefficient partition. No image/golden/runtime Python arithmetic changes.

K2 reads 16 words, K4 reads 32. K8 reads all 64 words twice: lower four slots,
first-group computation, then upper four slots. This costs 2,048 logical read
bytes instead of storing a separate 512-byte upper-slot cache. The lease
spans both groups. Occupancy plus pending read reserves at most two words;
the feeder holds input stable through decoder backpressure.

The actual final coefficient acceptance releases the source on that clock.
The test refills that bank for N+2 while N computes and N+1 remains ready,
with no ready-wait inserted between block requests. Every accepted decoder
leaf/slot beat and resulting audio sample is checked. Larger streams wrap
32-bit frame tags through zero. No oscillator phase precision is changed.

Misses submit no coefficients and perform no payload reads. They return the
last complete decoded block, initially silence. At fixed K/headroom this is
exact retained-coefficient reconstruction. A 128-byte history updates only
on accepted decoder output and becomes valid only at complete-block commit.
Reset invalidates partial history and all ownership/decoder state; shared
DMA/adapter reset is mandatory. The caller still retires obsolete unadmitted
requests and advances/freezes upstream musical state as appropriate.

Exact no-stall block request through final audio acceptance: 331 clocks K2/K4,
642 K8; fallback 18. Tested periodic output stalls produce 339..343 and
650..654 clocks respectively; fallback 26..30. These are finite traces, not
arbitrary-backpressure bounds. Prefetch DMA, source generation, other voices,
operators, mixing and effects remain additional. K2 still exceeds its 100-clock
tier estimate. The 40,000-clock shared DMA window and 133,333-clock audio
budget are unchanged and not qualified for the aggregate synthesizer.
