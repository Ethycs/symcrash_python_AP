Coefficient buffer ownership evidence - 2026-10-30

Requirements: WSE-STD-BRAM-RAM sections 3.1, 5.3, 8.1 and 11.
Two complete coefficient frames, publication only after successful consumed
DMA completion, exclusive DSP lease, and no reuse until outstanding writes
drain. Existing N=64, K=2/4/8, signed 16-bit coefficients and 64-bit DMA
descriptor are unchanged. Service classes 0..3 map to wire priorities 15..12.

Payload is external: 512/1,024/2,048 bytes for two frames, starting at 0x8000
inside the original 32 KiB partition. This does not count physical RAM or
establish aggregate packing. Control stores 32-bit identity tags and complete
descriptors; tags do not change pitch or phase precision. Duplicate live tags
backpressure admission. Only one DSP lease is allowed; invalid release is
diagnosed without freeing a different buffer.

One pending descriptor register precedes the shared queue. It is stable under
backpressure, even after cancellation. Miss/cancel retains queued/active
ownership until completion; late data is discarded. READY cancellation frees
the bank; cancellation cannot free a leased bank. Full descriptor matching
ignores other clients' completions. Failed status emits a tagged fault pulse.
Reset must flush owner, queue and RAM adapter together; no epoch/replay tags
were added to the descriptor. Exactly-once completion remains required.

Accepted acquisition registers its result at that edge, without waiting for
RAM. A completion on the same edge is too late for that acquisition. Explicit
cancellation wins over acquiring a READY frame. Missing data returns no lease;
actual fallback audio is the DSP caller's responsibility and remains open.

Six simulation configurations cover K=2/4/8 with independent request/response
stalls enabled/disabled, using the actual unchanged dma_priority and dma_burst.
They check full payload through a synchronous DSP port, reserved addresses,
exact frame lengths/priorities, duplicate tags, full admission, queued/partial/
ready/leased cancellation, completion races, unrelated completions, invalid
releases, first/middle/last response errors, invalid alignment and overdue
service. Ten resets per workload include eight interrupted ownership stages.
Memory outside both reserved buffers is checked unchanged.

A 256-block stream per configuration primes N and N+1, consumes all N input,
releases its source bank, then prefetches N+2 while N+1 remains ready. Tags
wrap through zero. This demonstrates the ownership sequence; the production
caller still supplies the schedule and must connect release to actual decoder
input acceptance. Decoder computation/audio is not simulated by this harness.

Realtime scope: pending submission adds one clock before queue acceptance.
Acquire/publish/release are single-edge state transitions. Queue wait, dispatch,
bus service and completion backpressure remain additional. Deliberate overdue
service reaches 40,028..40,092 clocks; those are fault cases, not deadline passes.
The 40,000-clock shared DMA window and 133,333-clock audio budget are unchanged.
No aggregate admission or device/PHY latency bound is claimed.
